# OpenRocket Simulations

This directory is reserved for OpenRocket design files and simulated flight-performance results.

## Planned Contents

- OpenRocket (`.ork`) design file.
- Predicted apogee and flight trajectory.
- Stability analysis (CG and CP).
- Flight velocity and duration estimates.
- Parachute descent velocity.
- Simulation graphs and exported results.

## Notes

Simulation results represent predicted performance and should not be confused with actual flight telemetry.

Actual flight measurements are documented separately in the `Flight-Data/` directory.
